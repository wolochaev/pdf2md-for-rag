## [0.1.0] - 2026-11-23

### Added

- Initial public release of the batch PDF-to-Markdown converter.
- Structured Markdown output with tables, formulas, and YAML metadata.
- Optional figure export and DOI extraction from article headers.
- A worked example comparing file sizes and estimated text token counts.
